> [!info] This window provides a summary of all of the project information and commands, in YAML format.
>
> - The first tab, **Project YAML**, contains all of the information in the project. This is the form that is used when the project is ready to  [[7. Glossary#Execute|Execute]].  Edits made here will be reflected in the other dialogue boxes.
> - The second tab, **Target Model**, contains a summary, in YAML format, of the model that Shape Shifter will evaluate the project against during validation. This summary is read-only and cannot be edited from within a Shape Shifter project.

![[SEAD Shape Shifter User Manual/images/SEAD Shape Shifter YAML Window.png]]

> [!warning]+ Any edits on this page must be done in correct YAML format. If you are uncertain, use the other dialogue boxes.
