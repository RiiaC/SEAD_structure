> [!info]+ This is where you will find the full list of data sources that are available for data mapping to SEAD, and where you can upload a new data source.

![[SEAD Shape Shifter User Manual/images/SEAD Shape Shifter Data Sources Window.png]]

To upload a new data source you will need to give it a unique name, and specify its file type. Currently supported file types are:

- CSV
- Excel (Pandas)
- Excel (Openpyxl)
- SQLite
- PostgreSQL
- MS Access
