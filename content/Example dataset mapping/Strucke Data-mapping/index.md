> [!info] This folder contains notes from using [my copy of Bruno's Shapeshifter project](https://shape-shifter.sead.se/projects/Brunos_copy_Riia_Strucke_v8) to accomplish the data mapping of the Strucke Radiocarbon data set.
> This dataset represents the largest available compilation of radiocarbon dates from archaeological contexts in Sweden, comprising 30,301 entries. It was compiled over the course of many years by Ulf Strucke, from published radiocarbon results. The final version of the Strucke dataset, StruckeC14\_Sweden\_v09.xlsx,  was sent to us on 2026-08-14, in conjunction with being [published to Zenodo](https://zenodo.org/records/21932353)  (where the version numbers have started over with v1).
>
> This Shape Shifter project contains code for separating different types of information in a single column to separate columns for ingesting to SEAD. These notes began as a duplicate [of my notes from my own Shape Shifter project for this dataset](obsidian://open?vault=SEAD_structure_Obsidian\&file=Example%20dataset%20mapping%2FStrucke%20Data%20mapping%2Findex), and are being edited to reflect the above linked dataset, starting on 2026-09-16. Any page in this section that was last updated prior to that date has not yet been edited to show the contents of this Shape Shifter project.

The file contains the below listed columns, which are as described below. This is still a work in progress. For the various mapped entities the "status" refers to weather or not there is a corresponding SEAD Shape Shifter entity already in existence, and if that entity needs further edits before it is ready for use in data ingestion.

- on [[2026-08-18]] I added two new columns, one for `material_edited` and one for `modification`. These were made these by copying the original `material` column, using Excel's text to columns function to break that to columns at commas and spaces, and then for the ones that broke into more than two columns using the replace option to consolidate the extra words into the appropriate column. I also changed "förkolnat frö" to place "frö" in the material column and "förkolnat" in the modification column. The original `material` remains column unchanged, so my work can be checked. Indeed, this step will also be done in Shape Shifter, so this is more of a check to see if the results are as expected.
