> [!info] > This folder contains my notes from working with the **C14\_Strucke\_merge\_2026\_02\_02.csv** document in SEAD Shape Shifter. However, as of 2026-05-04 a new, improved, version of that dataset was delivered. Therefore, the notes from working with that version have been moved to this sub-folder, and as soon as each entity has been re-created for the new version of the dataset, they will be removed form this folder. When this folder is empty that part of the work will be complete, and this folder may be deleted.
>
> It was known from the beginning that the C14\_Strucke\_merge\_2026\_02\_02.csv file was not the final, complete version of the Strucke collection of radiocarbon data. However, it was close enough to the final form to begin doing serious mapping work with it, in preparation for receipt of the final document. This folder will contains one page for each entity created in the mapping process in Shape Shifter, plus any explications or questions encountered in the process.
> **As of 2026-03-10** these notes will be implemented in the [SEAD Shape Shifter project riia-strucke-excelfil-test](https://shape-shifter.sead.se/projects/riia-strucke-excelfil-test), which has a datasheet made from an excel version of the above named document, in which the column names were edited to remove non-English characters and capital letters.
