> [!info] Gives a name to the full dataset, in this case: _Strucke data_

- create the fixed-value entity **datasets** with **dataset\_id**
  on the Basic tab
- under Columns, add **dataset\_name**
- under Fixed Values Data press ADD ROW
- enter "_Strucke data_" under **dataset\_name**
- needs a connection to [[Example dataset mapping/Strucke Data mapping/first draft of dataset/Entity methods|Entity methods]]
- later, when Sakarias and colleagues publish the paper based on this dataset, it can be added and linked with the foreign key bibilo\_id for that paper in [[Example dataset mapping/Strucke Data mapping/Entity biblio|Entity biblio]]
